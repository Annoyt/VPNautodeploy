# Текущая Архитектура (As-Is)

## Схема
```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│ Пользователь│────▶│  Entry Node  │────▶│  Exit Node  │
│             │     │  (iptables)  │     │  (3X-UI)    │
└─────────────┘     └──────────────┘     └──────┬──────┘
                                                │
                                         ┌──────▼──────┐
                                         │  vpn-bot    │
                                         │  (Docker)   │
                                         └─────────────┘
```

## Компоненты

### Entry Node (<entry-host>)
- **Роль:** Принимает подключения от пользователей
- **Технология:** iptables DNAT + MASQUERADE
- **Порты:** 443, 8443
- **Проблема:** Только одна нода, нет failover

### Exit Node (<old-blocked-host>)
- **Роль:** VPN backend (3X-UI + Xray)
- **Технология:** Docker + 3X-UI + VLESS Reality
- **Порты:** 443, 2026, 8443
- **Проблема:** Точка отказа

### VPN Bot
- **Роль:** Telegram бот для управления
- **Технология:** Python + SQLite
- **Проблемы:**
  - Прямой доступ к БД 3X-UI через volume mount
  - Статичная конфигурация (IP в env)
  - Нет поддержки multi-node

## Проблемы текущей архитектуры

1. **Один Exit Node** - точка отказа
2. **Прямой доступ к БД** - требует volume mount, конфликты прав
3. **Нет failover** - если Exit падает, все пользователи offline
4. **Статичная конфигурация** - Entry IP прописан в коде
