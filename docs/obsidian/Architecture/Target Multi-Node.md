## Компоненты

### 1. VPN Bot (Orchestrator)
**Роль:** Центральное управление
**Новые сервисы:**
- `NodeManager` - управление нодами
- `HealthMonitor` - мониторинг и failover
- `MultiNodeXUISync` - синхронизация с несколькими Exit Nodes

### 2. Entry Nodes (2-3 шт)
**Роль:** Прием пользовательских подключений
**Города:** Москва, СПБ, Казань (пример)
**Технология:** iptables DNAT

### 3. Exit Nodes (2-3 шт)
**Роль:** VPN backend
**Локации:** Frankfurt (primary), Amsterdam, Helsinki
**Технология:** 3X-UI + Xray

## Преимущества

| Аспект | До | После |
|--------|-----|-------|
| Отказоустойчивость | Нет | Auto-failover |
| География | 1 регион | Мульти-регион |
| Масштабируемость | Ручная | Авто (round-robin) |
| Мониторинг | Нет | Health checks |

## Риски

| Риск | Митигация |
|------|-----------|
| 3X-UI API не поддерживает добавление клиентов | Fallback на прямой доступ к БД |
| Рассинхронизация клиентов | UUID уникальны, проверка при добавлении |
| Пользователи получат разные IP при failover | Уведомление + инструкция по обновлению |
