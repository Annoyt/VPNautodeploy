# Admin Flows - VPN Bot

## Режимы работы

### Режим 1: С форум-группой (рекомендуется)
- Все действия в темах форума
- Структурированная работа
- История сохраняется

### Режим 2: Только PM (минимальный)
- Все через личные сообщения боту
- Быстрый старт
- Подходит для 1-2 админов

---

## Режим 1: С форум-группой

### Структура форума

```
📊 VPN Admin Panel (группа)
├── 📈 Statistics (топик 18)
│   └── Авто-отчеты, команда /stats
├── 📝 Requests (топик 15)  
│   └── Новые заявки, кнопки Approve/Reject
├── 💳 Payments (топик 16)
│   └── Проблемы с оплатой, уведомления
├── 🆘 Support (топик 17)
│   └── Тикеты пользователей
└── ✅ Solved (топик 37)
    └── Архив закрытых тикетов
```

### Flow 1.1: Обработка заявки

**Новая заявка в Requests:**
```
┌─────────────────────────────────────┐
│ 🆕 Новая заявка на демо              │
│                                     │
│ Пользователь: @username             │
│ ID: 123456789                       │
│ Язык: Русский                       │
│                                     │
│ [✅ Одобрить]  [❌ Отклонить]       │
│ [💬 Написать]  [👁 Профиль]         │
└─────────────────────────────────────┘
```

**Действия:**

1. **Одобрить** (`✅ Одобрить`)
   - Пользователь получает выбор платформы
   - Создается клиент в X-UI
   - Уведомление в Requests: "✅ Одобрено"

2. **Отклонить** (`❌ Отклонить`)
   - Запрос причины (спам/недостаточно данных/другое)
   - Пользователь получает сообщение с причиной
   - Уведомление в Requests: "❌ Отклонено"

3. **Написать** (`💬 Написать`)
   - Ссылка tg://user?id=123456789
   - Открывает PM с пользователем

4. **Профиль** (`👁 Профиль`)
   - История заявок
   - Текущий статус
   - Использованный трафик

### Flow 1.2: Работа с поддержкой

**Новый тикет в Support:**
```
┌─────────────────────────────────────┐
│ 🎫 Тикет #123 от @username          │
│ ID пользователя: 123456789          │
│                                     │
│ Проблема:                           │
│ Не подключается на iPhone, ошибка...│
│                                     │
│ [✅ Закрыть тикет]                  │
└─────────────────────────────────────┘
```

**Ответ:**
1. Reply на сообщение в топике
2. Бот пересылает ответ пользователю в PM
3. Пользователь отвечает в PM
4. Бот добавляет в топик с пометкой "👤 Пользователь:"

**Закрытие:**
1. Кнопка `✅ Закрыть тикет`
2. История копируется в Solved
3. Пользователь получает: "✅ Тикет закрыт"
4. Topic закрывается

## Режим 2: Только PM

### Настройка
```python
FORUM_ENABLED = False
ADMIN_ID = "1652899"
```

### Flow 2.1: Обработка заявки

**Новая заявка (PM админу):**
```
🆕 Новая заявка на демо

Пользователь: @username
ID: 123456789

Ответьте на это сообщение:
/approve 123456789 - одобрить
/reject 123456789 [причина] - отклонить
```

### Flow 2.2: Поддержка

**Пересылка вопроса (PM админу):**
```
🆘 Вопрос от @username (ID: 123456789)

Текст вопроса...

---
Ответьте на это сообщение для ответа пользователю
```

### Flow 2.3: Команды

```
/stats - Полная статистика
/pending - Список ожидающих
/approve ID - Одобрить заявку
/reject ID [причина] - Отклонить
/user ID - Информация о пользователе
/broadcast [текст] - Рассылка всем
/backup - Бэкап БД
```

## Разграничение прав

### SUPER_ADMIN
- Все команды
- Настройки бота
- Управление админами

### ADMIN
- Одобрение/отклонение заявок
- Ответы в поддержке
- Просмотр статистики
- Бан/разбан пользователей

### SUPPORT
- Ответы в поддержке
- Просмотр профилей пользователей
- Без доступа к заявкам и настройкам

```python
ADMINS = {
    "1652899": "super_admin",
    "1234567": "admin", 
    "7654321": "support"
}
```

## Уведомления админу

### Критические (моментально)
- Бот упал и перезапустился
- Ошибка БД
- X-UI недоступен

### Важные (в течение минуты)
- Новая заявка
- Проблема с оплатой
- Новый тикет в поддержку

### Информационные (ежедневно)
- Статистика за день
- Предупреждения о ресурсах (CPU/RAM)
