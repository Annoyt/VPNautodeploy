# User Flows - VPN Bot

## Общие принципы

1. **Минимальные действия** - пользователь делает ≤3 клика до результата
2. **Ясная обратная связь** - после каждого действия есть подтверждение
3. **Восстановление доступа** - ключ можно получить повторно
4. **Поддержка 24/7** - всегда есть кнопка "Поддержка"

---

## Flow 1: Новый пользователь (первое посещение)

### Шаги:

1. **/start**
   - Приветствие на языке пользователя
   - Краткое описание сервиса
   - Кнопка "🚀 Запросить демо"

2. **Нажимает "Запросить демо"**
   - Сообщение: "Заявка отправлена администратору. Ожидайте подтверждения."
   - Статус: `PENDING_DEMO`
   - Уведомление админу (в форум или PM)

3. **Админ одобряет**
   - Сообщение: "✅ Ваша заявка одобрена! Выберите платформу:"
   - Кнопки: Android, iOS, Windows, macOS, Другая

4. **Выбор платформы**
   - Показывается инструкция для выбранной платформы
   - Кнопка "📋 Получить ключ"

5. **Получение ключа**
   - VLESS ссылка (копируемый текст)
   - Инструкция по импорту
   - Кнопки: "📊 Статистика", "💬 Поддержка", "🔑 Мой ключ"
   - Статус: `ACTIVE`

### Коды состояний:
```
NEW → PENDING_DEMO → PLATFORM_SELECT → ACTIVE
```

## Flow 2: Существующий пользователь

### Сценарии:

**A. Проверить свой ключ**
```
[Главное меню] → "🔑 Мой ключ"
→ Показать VLESS ссылку + QR код
→ Кнопка "Скопировать"
```

**B. Посмотреть статистику**
```
[Главное меню] → "📊 Статистика"
→ Показать: использовано/осталось трафика
→ Дата окончания (если есть)
→ Статус подключения
```

**C. Написать в поддержку**
```
[Главное меню] → "💬 Поддержка"
→ Сообщение: "Опишите вашу проблему"
→ Пользователь пишет текст
→ Создается тикет в форуме (или PM админу)
→ Ответ приходит в этот же чат
```

**D. Купить полную версию**
```
[Главное меню] → "💎 Полная версия"
→ Информация о тарифах
→ Кнопка "Оплатить"
→ Перенаправление на платежную систему
→ После оплаты: уведомление админу
```

## Flow 3: Проблемы и решения

### Проблема: Ключ не работает
```
Пользователь: "У меня не подключается"
Бот: "Давайте проверим. Выберите:
      1. Не импортируется ключ
      2. Импортируется, но нет интернета
      3. Работал раньше, перестал"
→ В зависимости от ответа:
  - Инструкция по решению
  - Или создание тикета в поддержку
```

### Проблема: Забыл платформу
```
Пользователь может:
1. Заново выбрать платформу в меню
2. Получить инструкцию для другой платформы
3. Скачать приложение для текущей
```

### Проблема: Трафик закончился
```
Бот: "⚠️ Демо период закончен (5GB использовано)
      Для продолжения:
      [Купить полную версию]"
→ Переход в Flow покупки
```

## Flow 4: Мультиязычность

### Автоопределение
- При первом `/start` - язык из Telegram
- Если язык не поддерживается (не ru/en) - показать выбор

### Переключение языка
```
[Настройки] → "🌐 Язык"
→ Кнопки: 🇷🇺 Русский, 🇬🇧 English
→ Применить мгновенно
```

### Поддерживаемые языки
```python
LANGUAGES = {
    'ru': 'Русский',
    'en': 'English'
}
```

## Обработка ошибок

### Ошибка сети
```
"⚠️ Не удалось отправить заявку. Проверьте подключение и попробуйте снова."
[Повторить]
```

### Ошибка базы данных
```
"⚠️ Техническая ошибка. Мы уже уведомлены и исправляем проблему."
→ Автоматическое уведомление админа
```

### Пользователь заблокирован
```
"Доступ ограничен. Обратитесь в поддержку: @support"
```
