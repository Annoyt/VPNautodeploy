# NekoVPN 0.9.x-neko.6: простой режим, защита канала, исключения, диагностика сети

Решение владельца 20.11.2026: «делаем все доработки, включая доработки, которые потребуются в боте и интерфейсе, и покрываем всё тестами». Интерфейс — по доске `ui-board/boards/nekovpn.summary.md` (экраны «Главная», «Главная — нет подписки», «Выбор сервера», «Подписки», «Настройки», «Не подключается», «Вкладки в расширенном режиме»). Память: `project-nekovpn-simple-mode`, `project-app-exclusions-network-telemetry`.

## Решения владельца

- **Простой режим по умолчанию.**
  - Две вкладки: «Главная» и «Настройки».
  - Переключатель «Расширенный режим» возвращает четыре вкладки: «Главная», «Прокси», «Профили», «Настройки» — и все пункты FlClash.
- **Главная:**
  1. Блок пополам. Сверху «↻ Обновить подписку». Слева срок подписки и трафик. Справа кнопка подключения, под ней «● Работает» и время работы.
  2. Блок страны: название мельче, наибольшая скорость загрузки и отдачи за сеанс. Нажатие открывает выбор сервера.
  3. «Не подключается?» — открывает экран SOS.
  4. «Подписка: <имя> ›» — последней строкой, открывает список подписок.

  В расширенном режиме ниже блока страны идут карточки старой «Панели».
- **Подписки нет.** Кнопка серая. Нажатие открывает окно «Нужна подписка» с тремя кнопками:
  - «Добавить подписку» — ссылка или QR;
  - «Отправить запрос в Telegram» — `t.me/<бот>?start=app`;
  - «Запросить письмом» — `mailto`.
- **Выбор сервера.** Первая строка — «Зона выхода: Авто / страны». Видна, только если серверы есть в нескольких странах.
- **Подписки.** Ещё «Попросить подписку: в Telegram-боте / письмом». Подписок может быть несколько.
- **Настройки.**
  - Простые: язык, тема, «Приложения без VPN», автовключение и обновления, «О программе», «Расширенный режим».
  - Пункт «Не подключается» в настройках убран.
  - Наверху расширенных — «Диагностика сети»: «Помогать искать блокировки», по умолчанию выключено.
  - Переход в простой вид диагностику НЕ выключает.
- **Экран SOS.** Ещё «Нет связи? Напишите письмом» — `mailto` с темой «SOS»: на такое письмо бот отвечает сам (§33 E24).
- **Первый запуск.** Галочка вместо набора фразы и карточка «Добавьте подписку».
- **Защита канала.**
  - Локальный прокси получает случайный пароль по умолчанию.
  - «Системный прокси» выключен по умолчанию.
  - Внешний контроллер закрыт, как и сейчас.
- **Исключения.** Приложения сервисов из белых списков РФ идут мимо VPN. Список приходит в подписанных настройках.
- **Диагностика сети.**
  - Этап 1 (анонимно, без места) — у всех.
  - Этап 2 (вышка, код зоны, район) — только по выключателю.
  - Разрешение — «только во время использования». Пока VPN включён, служба VPN — foreground service с типом `location`, поэтому «всегда» не нужно. Владелец спросил прямо 20.11: «всегда» не запрашиваем.
    - VPN включён из свёрнутого приложения (плитка, автозапуск) — тип `location` не ставим. Сбор пропускается, падения нет.
  - Свёрнутое приложение не падает: без разрешения сбор просто пропускается.
  - Данные идут на российский сервер — бот на entry. В них нет подписки, Telegram и IP. Отправка только через туннель.
- **Баги.**
  - Повторная ссылка `nekovpn://` создаёт дубликат «Имя(1)».
  - `profile-update-interval` применяется только при первом скачивании.

## Договорённости между приложением и ботом

### D1. Подписанные настройки (schema 1, новые ключи; старые версии их пропускают)

- `bypass_apps`: массив имён Android-пакетов.
  - Формат: `^[a-zA-Z][a-zA-Z0-9_]*(\.[a-zA-Z][a-zA-Z0-9_]*)+$`.
  - Без повторов, не больше 300.
- `mail`: адрес ящика сервиса для `mailto` или `null`.
- `flags.netstat`: `false` — приложение ничего не отправляет. Если ключа нет, это `true`.

### D2. Приёмник диагностики (бот, entry)

- `POST /api/neko/netstat`.
  - Заголовок `Authorization: NekoToken <токен подписки>` — тот же токен, что в `/sub/<token>`.
    - С 20.11: не `X-Neko-Token`. Caddy скрывает в журнале только `Authorization` и `Cookie`.
  - Сервер проверяет, что подписка активна, и токен выбрасывает. Не хранить и не писать в журналы, и токен, и IP.
- Тело (≤ 64 КБ, ≤ 100 событий):
  ```json
  {"v": 1, "app": "0.9.2-neko.6", "events": [
    {"ts": 1795190400, "kind": "drop", "net": "cell", "mcc": "250", "mnc": "01", "rat": "lte",
     "level": 2, "ru": true, "ours": false, "proto": {"hy2": false, "stls": false},
     "cell": {"tac": 7701, "cid": 123456789, "pci": 301, "earfcn": 1850}, "area": "ucfv0"}
  ]}
  ```
  - `ts`: unix-время, округлённое вниз до 10 минут.
  - `kind`: `drop` — наш канал не работает; `ok` — работает, раз в час при включённом VPN.
  - `net`: `wifi` / `cell` / `other`.
  - `mcc` / `mnc`: строки из цифр или `null`.
  - `rat`: `gsm` / `umts` / `lte` / `nr` / `unknown`.
  - `level`: 0–4 или `null`.
  - `ru`: открылся ли напрямую, мимо туннеля, российский сайт: `true` / `false` / `null`.
  - `ours`: работает ли наш канал.
  - `proto`: необязательно, итог проверки протоколов.
  - `cell` и `area`: только этап 2. `area` — geohash длиной 5, примерно 5 км.
- Ответы:
  - 204 — принято;
  - 400 — неверное тело;
  - 401 — нет токена или он неверный;
  - 413 — слишком большое тело;
  - 429 — больше 30 запросов в час на одну подписку.
- Хранение: таблица `netstat_events` без токена, `chat_id` и IP. Записи старше 14 дней удаляются ежедневной джобой.
- Сервер строгий (B1, 20.11):
  - неизвестное поле или пустой `events` — 400;
  - обязательные поля: `ts` (целые секунды < 2^32), `kind`, `net`, `ours`;
  - `mcc` — ровно 3 цифры, `mnc` — 2–3 цифры;
  - `cell` — только `tac`, `cid`, `pci`, `earfcn`, в допустимых пределах. «Недоступно» из Android отправлять как null.
- Приложение не пишет `drop`, пока подписка истекла или трафик кончился.
- `netstat_events` не попадает в ежедневную резервную копию.

### D3. `t.me/<бот>?start=app`

- Есть активный ключ: ответ с кнопкой «Открыть в NekoVPN» → `/open/<token>` (§38), подписка добавляется в приложение сама.
- Ключа нет: обычный путь нового пользователя, как сейчас при запросе демо.

### D4. Письма

- «Запросить письмом» → `mailto:<mail>?subject=NekoVPN: запрос подписки`. Заявку админу создаёт mail_intake (§33).
- «Нет связи? Напишите письмом» → тема «SOS NekoVPN». Если адрес привязан через `/setemail`, бот отвечает сам (E24).

## Замечания к диагностике (PR #27)

- **Фоновая геолокация уже объявлена в APK.** Плагин FlClash `wifi_ssid` объявляет в своём манифесте `ACCESS_BACKGROUND_LOCATION`, и он попадает в общий манифест. Мы её никогда не запрашиваем.
  - Можно убрать через `tools:node="remove"`.
  - Сначала проверить, нужна ли она «Памяти сетей» (имя Wi-Fi в фоне).
- **Проверки идут в движке Flutter.** Если смахнуть приложение из недавних, VPN работает, а проверки стоят до следующего открытия.
- **Ограничение на комментарии в русской локали не работает.** Хук печатает долю с запятой, и awk сравнивает её как текст. Мерить с `LC_ALL=C`.
  - 20.11 мои модули #24 и #25 превышали лимит (15–27%). Исправлено отдельными коммитами: 2,5–2,8%.
